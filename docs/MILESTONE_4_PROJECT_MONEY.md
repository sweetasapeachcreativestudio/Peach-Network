# Milestone 4 — Project Money Controls

This milestone connects Peach Coins to actual projects.

## Added
- Service-to-coin recommendation engine
- Project creation API
- Trusted coin hold function
- Creative offer acceptance
- 72-hour offer expiration enforcement
- Cancellation review protection
- Trusted project completion
- Held coins become spent at completion
- Creative payout obligation created from the accepted offer
- Stripe Connect payout readiness status:
  - Not Started
  - Information Needed
  - Action Required
  - Ready to Receive Payments

## Important
Peach does NOT automatically refund a client after work may have begun.
Accepted/in-progress projects go to cancellation/dispute review.

Peach does NOT change the creative's agreed payout at completion.
The payout obligation is created from the exact accepted offer.
